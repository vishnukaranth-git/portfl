## ✨ Features & Architecture

- **High-Performance Scrollytelling Canvas**:
  - HTML5 Canvas rendering engine scrubbing across a 240-frame cinematic image sequence.
  - Custom `object-fit: cover` scaling algorithm maintaining aspect ratio across desktop and mobile.
  - Image preloading and frame caching with `requestAnimationFrame` for buttery-smooth 60fps scrubbing with zero flicker.
- **Cinematic Staged Storytelling Overlay**:
  - Dynamic opacity, blur, and parallax transitions synchronized to scroll progress.
- **Modern Tech Stack**:
  - **Framework**: Next.js 14 (App Router)
  - **Language**: TypeScript
  - **Styling**: Tailwind CSS with custom deep navy, electric blue, and warm orange palette
  - **Animation**: Framer Motion
  - **Icons**: Lucide React
- **Editorial Portfolio Sections**:
  - About Me & Highlights
  - Academic Foundation (BMSIT&M)
  - Experience Timeline (Elevance Skills, Google Student Ambassador 2026, EBTS Technologies)
  - Selected Work with interactive project launch cards
  - Technical Arsenal (AI/ML, Programming, Development)
  - Recognition & Hackathon Distinctions (Google Office Top 20, HackArena Top 15)
  - Certifications (Google / Simplilearn, Cloud Architect, Oracle)
  - Contact Section with Direct Gmail Web Composer integration

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ (tested with v20 / v24)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/vishnukaranth-git/portfl.git
cd portfl

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### Production Build

```bash
npm run build
npm start
```
